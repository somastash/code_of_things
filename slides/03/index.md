*#2* ではタクトスイッチのボタン押下状態をマイコンから取得する方法を学んだ。

<hr>

<span class="blue">押していない</span>時、ボタンは導通していないため、入力ピンの電圧は `HIGH` になる。

```
5V 電源 ➔ 入力ピン（プルアップ抵抗） ➔✗ ボタン（非導通）
```

<span class="red">押している</span>時、ボタンは導通しているため、回路は `GND` に繋がる。
結果、入力ピンの電圧は `LOW` になる。

```
5V 電源 ➔ 入力ピン（プルアップ抵抗） ➔ ボタン（導通） ➔ GND 
```

この電圧の高低を *`if`* 文で判定することで**処理を分岐**させ、出力を変化させることができた。

---

しかしこの方法では ON か OFF 、2 通りの入力しか検知できない。
一方で自然界には温度や圧力、加速度など、ON / OFF では表現できない物理量が存在する。
これらの情報を電子機器が入力として受け取るにはどうすればいいだろうか。

---

# アナログ入力

---

ON / OFF の 2 通りの信号しかない入力のことを**デジタル入力**と呼ぶ。
それに対し、*連続的に変化する信号*を扱う入力のことを**アナログ入力**と呼ぶ。

温度, 圧力, 加速度といった物理量は、電子回路に組み込まれた*センサー*によって測定され、
電気信号に変換される。
マイコンはそれを*数値*として読み取り、プログラムがその情報を適切に処理する。

---
